# 🔐 Authentication

## Current Status
The API currently operates **without authentication** (open access). This is intentional for the initial development phase.

## Planned (Future Phase)
A JWT-based authentication system is planned for a future phase to support:
- User accounts
- Per-user monitor configurations
- Secure API access

## Security Note
Until authentication is implemented, the API should not be exposed publicly without an API gateway or reverse proxy providing access control.
