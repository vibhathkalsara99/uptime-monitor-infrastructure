# 📐 Architecture Decision Records (ADR)

## What is an ADR?
An **Architecture Decision Record** captures a significant architectural decision, the context behind it, and the consequences of choosing it. It creates a permanent, version-controlled record of *why* the system is built the way it is.

## ADR Template
```markdown
## Status
[Proposed | Accepted | Deprecated | Superseded by ADR-XXX]

## Context
What is the situation that is driving this decision?

## Decision
What was decided?

## Consequences
What are the results of this decision? (positive and negative)
```
